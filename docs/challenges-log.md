## Hypo A merged challenges

- **The headline changed:** the Hypo A half-open H1 windows and saved metric summary give 433,611 and 455,383, rather than the earlier notebook output. The older values remain historical, not blended into the new result.
- **The measure has limits:** the count is validated booking test lines. It is not proof that a sample was collected or that a test was performed.
- **Identity is still an assumption:** `person_id` is an analytical map built from normalized contact/name/date information. It should not be used for clinical identity or result routing.
- **System mix changed:** H1 2026 includes Nova records while H1 2025 is legacy. This is context for interpretation, not proof of a cause.
- **City labels need care:** the Hypo A work maps Bangalore to Bengaluru for the city view, but keeps the original fields unchanged and records the mapping as an audit rule.
